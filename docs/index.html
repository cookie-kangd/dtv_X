这是什么

dtv_mx 是一款面向 Android 手机的轻量化直播聚合应用，用 Kotlin Multiplatform + Jetpack Compose 编写，播放内核为 Android Media3（ExoPlayer）。它把 抖音直播、B站（哔哩哔哩）直播、斗鱼直播、虎牙直播 汇总到同一个 App 里，一个入口就能浏览分区、搜索主播、关注收藏、看实时弹幕，不必在多个平台的官方 App 之间反复切换。

只保留看直播真正需要的功能：没有广告、没有开屏、没有推荐信息流、不需要注册账号（仅 B站 直播在需要登录态时才用到登录）。安装包约 19 MB。

适合同时关注多个平台主播、嫌各家官方 App 太臃肿、想用一个 App 横屏看直播的人。

功能一览

支持平台抖音 / B站（哔哩哔哩） / 斗鱼 / 虎牙 直播
分区浏览按平台分类浏览直播列表，可订阅常用分区做快速入口，并记忆各平台上次所在分类
关注管理一键关注 / 取消关注；首页支持置顶与长按拖拽排序
搜索按平台搜索主播与直播间；B站支持登录 / 退出
播放Android Media3（ExoPlayer）内核；全屏与横竖屏适配；画质档位（最高 / 高 / 中 / 低）；多线路切换
弹幕实时弹幕；关键词屏蔽；字号、透明度、显示区域可调
退出清理「退出时清理缓存」开关（默认开启）：退出自动清理直播缓存与临时文件，登录状态、设置、关注列表全部保留
平台设置自定义底部导航显示哪些平台以及排列顺序
数据同步局域网共享 / 导入关注、分区订阅与屏蔽词
外观浅色 / 深色 / 跟随系统主题，可自定义主色调
更新设置内一键查询 Release 并下载安装

下载与安装

  • 前往 Releases 页面 下载 dtv-mx-<版本号>.apk，直接安装即可
  • 系统要求：Android 8.0（API 26）及以上，支持 arm64-v8a / armeabi-v7a
  • App 内更新：设置 → 检查更新，自动读取仓库 Release 并下载安装
  • 所有版本由 GitHub Actions 自动构建、使用同一签名证书，可直接覆盖安装，不会出现签名冲突

常见问题

装完打不开，或提示未知来源？

Android 8.0 以上需要在系统设置里允许该来源安装应用，允许后重新安装即可。

从旧版本 dtv_X 升级会丢数据吗？

不会。仓库与 App 名称由 dtv_X 更名为 dtv_mx，包名与签名证书均未改变，直接覆盖安装，关注列表与设置都会保留。

「退出时清理缓存」会把 B站 登录清掉吗？

不会。清理只针对播放缓存与临时文件目录；登录凭据、偏好设置、关注与订阅数据存放在独立位置，不参与清理。

某个平台的直播打不开了？

直播地址与列表来自第三方平台的公开接口，平台调整接口后可能失效，需要等版本更新适配。

支持投屏 / 录制 / 电视端吗？

目前不支持，仅面向 Android 手机端观看。
