# dtv_mx

安卓直播聚合 App —— 抖音、B站、斗鱼、虎牙 四大平台直播一站式观看（开源 / 免费 / 无广告 / 非官方）。

> 基于 [chen-zeong/dtv_mobile](https://github.com/chen-zeong/dtv_mobile) 的修改版本。

## 下载

前往 [Releases](https://github.com/cookie-kangd/dtv_mx/releases/latest) 下载最新的 `dtv-mx-<版本>.apk` 安装即可。
要求 **Android 8.0 及以上**；所有版本使用同一签名，可直接覆盖安装。

## 功能

- 四大平台直播：抖音 / B站（哔哩哔哩）/ 斗鱼 / 虎牙
- 分区浏览、搜索主播、关注收藏、实时弹幕
- 播放：横竖屏、画质档位、多线路切换
- 退出时清理缓存（默认开启，不清除登录与设置）
- 浅色 / 深色主题，可自定义主色调

## 常见问题

**从旧版 dtv_X 升级会丢数据吗？** 不会，包名与签名未变，覆盖安装即可保留关注与设置。

**「退出时清理缓存」会清掉 B站 登录吗？** 不会，只清理播放缓存与临时文件。

**某个平台的直播打不开了？** 第三方接口变动所致，等版本更新适配。
